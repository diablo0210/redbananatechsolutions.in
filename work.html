The engineering underneath

Gallery panels have no internet, so every byte of content ships embedded — the apps read nothing from the network because there is no network to read from. Power fails without warning, so every station boots straight back into its experience. Attendants change, so a curator can update content as data, without an engineer. And because a passing test only means something when failure is possible, our suites plant deliberate faults and prove the checks catch them — before every release, including this one.
